# hxwl-08 葡萄酒盲品训练

产区、品种与感官特征的盲品复习系统

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5108

## 玩法规则

- 一局五题，从 10 款酒的卡片库中随机抽取，每题四个选项
- 每题先展示香气关键词与酸度；拿不准可「看线索」翻看产区、品种、年份
- 直接答对得 100 分；看一次线索后答对得 60 分，记为首次成绩
- 答错得 0 分，题目排到队尾加练；加练答对只让练习继续，首次成绩不再回升
- 中途离开自动存档（localStorage），回来从当时的题和分数接着答
- 一局结束显示总分、逐题明细和错题酒款，方便安排后续复习

## 目录结构

- `src/data/wines.ts` — 盲品卡片库（产区、品种、年份、酸度、香气关键词）
- `src/game/session.ts` — 一局训练的出题、计分、加练队列与本地存档逻辑
- `src/App.tsx` — 界面：规则与卡片库、答题页、结算页
