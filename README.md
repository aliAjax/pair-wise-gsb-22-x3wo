# hxwl-08 葡萄酒盲品训练

产区、品种与感官特征的盲品复习系统

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5108

## 五题训练局

- 一局 5 款酒，根据产区、品种、年份、酸度、香气关键词猜酒款
- 不看线索直接答对记 100 分；查看一次线索后答对首次成绩记 60 分
- 答错（或主动看答案）首次成绩记 0 分，该酒排到队尾加练；加练只让练习继续，首次成绩不回升
- 训练进度与分数保存在浏览器 localStorage，中途离开再回来从当前题和已有分数继续
- 一局结束显示总分（满分 500）及错题酒款完整卡片，方便安排复习
